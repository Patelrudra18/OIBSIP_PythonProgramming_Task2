## Project Objective

The objective of this project is to develop a Body Mass Index (BMI) Calculator that helps users determine their BMI based on weight and height inputs. The application provides instant results along with health status classification to promote awareness about healthy body weight ranges.

---

## Project Description

The BMI Calculator is an interactive web application developed using Python and Streamlit. The application allows users to enter their weight and height, calculates the BMI using the standard formula, and categorizes the result into different health categories such as Underweight, Normal Weight, Overweight, and Obese.

The application is designed with a simple and user-friendly interface, making it easy for users to understand their BMI status.

---

## Steps Performed

1. Designed the user interface using Streamlit.
2. Collected user inputs for weight and height.
3. Implemented the BMI calculation formula.
4. Applied conditional logic to determine BMI categories.
5. Displayed BMI values and health classifications dynamically.
6. Added visual indicators and BMI reference information.
7. Tested the application using different BMI scenarios.

---

## BMI Formula

BMI is calculated using:

BMI = Weight (kg) ÷ Height² (m²)
