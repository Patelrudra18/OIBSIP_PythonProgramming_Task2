## Project Objective

The objective of this project is to develop a Body Mass Index (BMI) Calculator that helps users determine their BMI based on weight and height inputs. The application provides instant results along with health status classification according to standard BMI ranges.

---

## Project Description

The BMI Calculator is an interactive web application developed using Python and Streamlit. The application allows users to enter their weight and height, calculates BMI using the standard formula, and categorizes the result into Underweight, Normal Weight, Overweight, or Obese.

The application is designed with a simple and user-friendly interface, making it easy for users to understand and interpret their BMI results.

---

## Steps Performed

1. Designed the user interface using Streamlit.
2. Collected user inputs for weight and height.
3. Implemented the BMI calculation formula.
4. Added BMI category classification logic.
5. Displayed BMI results dynamically.
6. Included visual indicators and BMI reference information.
7. Tested the application using multiple BMI scenarios.

---

## BMI Formula

```text
BMI = Weight (kg) ÷ Height² (m²)
```
